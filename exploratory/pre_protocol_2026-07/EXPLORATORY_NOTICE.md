# Pre-Protocol Exploratory Material

This directory preserves work created before the authoritative experimental
protocol and before Git history was established.

The material is retained for provenance only. It must not be treated as a
definitive experiment, used to select the primary graph, or cited as validated
evidence for an encoding bound.

The two preserved `results.csv` files both report an optimiser value of
`L_max = 5`. The separately remembered exploratory claim that a heuristic
assignment reached `L_max = 4` is not backed by an artefact preserved in this
repository. The original `sphere_encoding_feasibility_l4` directory was empty
when Stage 1 began.

See `inventory.json` for original paths, relocated paths, baseline tracking
state, file hashes, sizes, classifications, and scientific status.
